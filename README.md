# 🚖 Cab Fare Calculator (C++)

## 📌 Description
This project calculates cab fare based on distance, waiting time, and cab type.

## 🚀 Features
- Multiple cab options (Mini, Sedan, SUV)
- Distance-based fare
- Waiting charges
- Surge pricing

## 🧠 Logic
Fare = Base Fare + (Distance × Rate) + Waiting Charges  
Surge pricing multiplies total fare by 1.5

## 💻 How to Run
1. Compile:
   g++ main.cpp -o cab
2. Run:
   ./cab
